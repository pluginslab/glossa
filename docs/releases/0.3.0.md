For laptops: a GPU box when you can reach it, the local model when you cannot.

**A fallback server.** Set `endpoint` to the fast server on your network and `fallbackEndpoint` to the local whisper-server:

```json
{
  "endpoint": "http://100.x.y.z:7576/v1/audio/transcriptions",
  "apiKey": "sk-…",
  "model": "transcribe",
  "fallbackEndpoint": "http://127.0.0.1:8178/inference"
}
```

When the primary fails for any reason, or stays silent for `primaryTimeout` seconds (default 10), the same recording goes to the fallback. The log says which server answered, and so does the menu. *Use Fallback Server* in the menu sends everything to the fallback until you uncheck it, for when you know you are offline.

**Remote `http://` endpoints work.** 0.2.0 could reach plain HTTP on 127.0.0.1 only; anything else failed with *App Transport Security policy requires the use of a secure connection* and the error sound. 0.3.0 allows it. `https://` endpoints are unaffected.
