One fix, for anyone whose Whisper server is not on the Mac itself.

**Remote `http://` endpoints work again.** Pointing `endpoint` at a server on your LAN or tailnet (a GPU box running Speaches or whisper.cpp, or an llm-router in front of one) failed every transcription with *App Transport Security policy requires the use of a secure connection*, with the error sound after each recording. macOS exempts 127.0.0.1 from that policy but nothing else, and 0.2.0 shipped without the exception. 0.2.1 allows plain HTTP, so the three-line config change in the README's "Remote servers" section does what it says. `https://` endpoints are unaffected.
