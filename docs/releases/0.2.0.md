Two things people asked for on day one.

**Music ducks while you dictate.** If something is playing when you press the mic key, the system volume drops by 10 points (configurable, `duckPercent`) for the length of the recording and comes back when you stop. Silence is left alone, and so is a volume you changed yourself in the meantime.

**Homebrew.**

```
brew install --cask pluginslab/tap/glossa
glossa-server
```

The cask installs the app and whisper-cpp; `glossa-server` downloads large-v3-turbo and starts the launch agent on 127.0.0.1:8178. DMG users get the same script inside the app, at `Glossa.app/Contents/Resources/install-server.sh`.

Signed and notarized universal build for macOS 14 or later.
