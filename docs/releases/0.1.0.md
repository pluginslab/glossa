Glossa replaces macOS Dictation with Whisper, and tells Whisper what you are about to say.

Apple's dictation has no way to learn a word. Whisper does: a short prompt of vocabulary and preceding text, and `Next.js`, `pnpm` or `PostgreSQL` come out exactly right instead of "next JS", "PNPM" and "Postgres SQL". Glossa builds that prompt for you on every dictation, from a glossary file and the text before your cursor, and types the result wherever you are.

**Highlights**
- Press the microphone key to start and stop, or hold it to talk. Fn double-tap and Fn hold work too. Apple's dictation never sees the key.
- Glossary in `~/.config/glossa/glossary.txt`, one term per line. Cursor context read through Accessibility, in apps that expose it.
- Local by default: whisper.cpp's `whisper-server` as a launch agent (`scripts/install-server.sh`), large-v3-turbo, about 0.6 s per sentence on an M-series Mac. Or point it at any OpenAI-compatible transcription endpoint on your network.
- Pastes through the clipboard and restores it afterwards.

**Install**
Download the DMG below, drag Glossa to Applications, run `scripts/install-server.sh` from a checkout (or point `config.json` at a server you already have), grant Accessibility and Microphone, and set the Globe key to "Do Nothing" and the Dictation shortcut to Off in System Settings → Keyboard.

Signed and notarized universal build for macOS 14 or later.
